# 塩田川 その4 左岸 完成形ビューア

二級河川塩田川 河川改修工事（その4）左岸 完成形の 3D ビューアです。
スマホのブラウザで開いて、部品の切り替え・透過・測点での断面・計測ができます。
Android では現地で 1:1 の AR 表示もできます。

## 中身

```
  index.html              画面と UI
  app.js                  three.js のビューア本体
  sd_model.json           形状と線形と測点（scripts\sd_viewer.py が作る・約 650 KB）
  model.usdz              iPhone/iPad の AR Quick Look 用（実寸 1:1・約 0.8 MB）
  manifest.webmanifest    ホーム画面に追加するための設定
  sw.js                   オフライン用（一度開けば電波が無くても見られる）
  icon-192.png / icon-512.png
```

`sd_model.json` は `scripts\sd_viewer.py` を実行すると作り直されます。
中身は AR モデル（`出力\AR\塩田川_AR_data.json`）＋設計線形＋測点対照表です。

## できること

```
  部品の表示ON/OFF   完成形の面・張ブロック・階段工・かごマット（平面図案／横断図案）など
  透過               面を透かして 基礎・均し・根固め を見る
  測点でスライス     現況測点で切って断面を見る。厚みも変えられる
  測点ラベル         成果簿の杭の位置と名前
  計測               2点をタップ → 水平距離・比高・斜距離
  タップで情報       どこを触っても 測点・離れ・標高・実座標が出る
  現地AR             1:1 で現地に重ねる（Android Chrome）
```

★かごマットは **平面図案（オリーブ）と横断図案（オレンジ）の2つ**が入っています。
どちらが正かは未確定です（引き継ぎ書 §8-c）。現地で見比べて監督員と決めてください。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例：`shiotagawa-viewer`）。**Public** にする
2. このフォルダの中身（`index.html` など7ファイル）をリポジトリ直下にアップロードする
   - ブラウザで「Add file」→「Upload files」にドラッグ＆ドロップでよい
3. リポジトリの **Settings → Pages** を開く
4. Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
5. 1〜2分待つと `https://<ユーザー名>.github.io/shiotagawa-viewer/` で開ける

★AR とカメラは HTTPS でないと動きません。GitHub Pages は HTTPS なので大丈夫です。

QR コードは、上の URL を QR 作成サービスに入れて作ってください。
現場で配るときは、印刷して詰所に貼っておくのが手軽です。

## 現地 AR の使い方（iPhone / iPad）

右上の「AR（実寸）」を押すと、iOS 標準の **AR Quick Look** が開きます。
ARKit のトラッキングがそのまま効くので、置いたあと歩き回っても位置が保たれます。

```
  1) Safari で開いて 右上の「AR（実寸）」を押す
  2) 「AR」タブに切り替える（Quick Look の画面上部）
  3) 地面を映すと自動で置かれる。1本指のドラッグで移動、2本指で回転
  4) 現地の杭や既設構造物に合わせる
```

```
  ★実寸（1:1）です。延長 195 m あるので、画面には一部しか入りません。
    見たい場所（階段工・かごマットなど）に立って、その付近に合わせてください。
  ★モデルは「平面の中心を原点、一番低いところを地面」に置いてあります。
  ★かごマットは 平面図案（オリーブ）と横断図案（オレンジ）が両方入っています。
  ★位置合わせは手動です。座標での固定ではないので、出来形の判定には使えません。
```

`model.usdz` は `scripts\sd_usdz.mjs` で作り直せます（ネットにつながる PC で
`npm i three@0.160.0` のあと `node sd_usdz.mjs ..\出力\Viewer\sd_model.json ..\出力\Viewer\model.usdz`）。

## 現地 AR の使い方（Android Chrome）

```
  1) 右上の「AR」を押す
  2) 床（地面）を映して、緑の輪が出るまで少し動かす
  3) 「基準の杭」で、いま自分が立っている杭を選ぶ（例 NO.99）
  4) 杭の足元に輪を合わせて「① 足元に合わせる」
  5) 堤防の上流側の地面に輪を向けて「② 上流へ向ける」
  6) ずれていれば「回転」「高さ」で微調整
```

★iPhone / iPad の Safari は WebXR AR に未対応です（2026年時点）。
　そのため iOS では上の AR Quick Look に自動で振り分けます。ボタンは同じです。
★モバイル PC に外部カメラをつないでも WebXR AR は動きません。
　Chrome の AR セッションは ARCore（Android 実機）が前提です。

## 注意

```
  ・座標系  JGD2011 平面直角座標系 第9系 ／ 標高 T.P.
  ・ローカル原点  X=84698.0  Y=78795.0
      X_JGD = モデルY + 84698.0 ／ Y_JGD = モデルX + 78795.0
  ・範囲  設計追加距離 1914.000〜2109.000（大型張ブロック区間 195.000 m）
  ・AR の位置合わせは手動です。座標での固定ではないので、
    出来形の判定には使えません。形と納まりの確認用です。
```
